Last updated: [05/01/2026]

By accessing or using CCAS (ClassCam Attendance System) ("the System", "we", "our"), you agree to be bound by these Terms & Conditions. If you do not agree, do not use the System.

1. Purpose of the System

CCAS is an academic tool designed to:

  • Capture classroom images and/or video
  • Perform automated attendance marking
  • Store attendance-related metadata
  • Support research and development in computer vision and machine learning

The System is intended strictly for educational and academic use.

2. Data Collected

The System may collect and process the following data:

  • Facial images and/or video frames
  • Facial embeddings or derived biometric features
  • Attendance records (presence, timestamps, class identifiers)
  • Device and system metadata (IP address, browser type, access logs)

No personal data is collected beyond what is necessary for attendance and research purposes.

3. Consent

By participating in classes where CCAS is used, students explicitly consent to:

  • Capture of their images/video during class
  • Processing of this data for attendance verification
  • Long-term storage of the data
  • Use of the data for machine learning model training, evaluation, and improvement

Participation in the class implies consent unless explicitly opted out through institutional procedures.

4. Data Retention

All collected data may be stored indefinitely

Data may be retained even after:

  • Course completion
  • Graduation
  • End of academic term

This retention is necessary for:

  • Long-term machine learning research
  • Model reproducibility
  • Performance benchmarking
  • Academic publications (in anonymized form)

5. Data Usage for Machine Learning

Collected data may be used for:

  • Training and fine-tuning ML models

  • Internal testing and academic experimentation

Important:

  • Any public release will be fully anonymized

6. Data Sharing

No third-party commercial sharing is permitted.
